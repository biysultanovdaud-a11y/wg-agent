# Security Policy

## Supported Versions

The following versions are currently supported with security updates.

| Version | Supported |
| ------- | --------- |
| 1.x | ✅ Yes |
| < 1.0 | ❌ No |

## Reporting a Vulnerability

If you discover a security vulnerability, please do not open a public GitHub issue.

Instead, report it privately by contacting:

- Email: biysultanovdaud@gmail.com

Please include:

- A description of the vulnerability.
- Steps to reproduce the issue.
- The potential impact.
- Any suggested mitigation or fix, if available.

## Response Process

After receiving a report:

1. We will acknowledge receipt as soon as possible.
2. We will investigate the issue.
3. If confirmed, a fix will be prepared.
4. A security release will be published when appropriate.

We appreciate responsible disclosure and will make every effort to resolve confirmed security issues promptly.
